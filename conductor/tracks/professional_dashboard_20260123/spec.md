# Specification: Professional Dashboard and Patient Management

## Context
Mental Health Professionals (Psychiatrists, Psychologists, Psychometricians) need a dedicated workspace to manage their patients and sessions efficiently. This track establishes the foundation for the Professional role's experience.

## Requirements

### 1. Professional Dashboard
*   **Overview:** Display a summary of today's appointments (placeholder) and quick access to the patient list.
*   **Navigation:** Side drawer or specialized navigation for professional tools.

### 2. Patient List Management
*   **Search/Filter:** Ability to search for patients by name.
*   **List View:** Display patient names, last mood summary, and last consultation date.

### 3. Patient Profiles (Basic)
*   **Summary:** View patient contact info and basic history.
*   **Mood Integration:** View a summary of the patient's recent mood history (shared data).

### 4. Consultation Notes
*   **Editor:** A simple, secure text editor for taking notes during a session.
*   **Persistence:** Save notes linked to a specific patient and date.

## Design
*   **Style:** Professional and Clinical (as per guidelines).
*   **Layout:** Side navigation or tabs suitable for more complex data management.
*   **Accessibility:** Clear typography and high contrast for clinical review.

## Acceptance Criteria
*   [ ] Professional can view a list of assigned patients.
*   [ ] Professional can search for a specific patient.
*   [ ] Professional can view a basic patient profile.
*   [ ] Professional can create and save a session note.
*   [ ] Professional dashboard is accessible only to the Professional role.
